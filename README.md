# CircuitX_Smart_Solver-

CircuitX is a basic Java-based Circuit Analysis software project developed for the Circuit Analysis (CA) course.

Project Information

- Project Name: CircuitX_Smart_Solver
- University: IBA Sukkur
- Department: Computer System Engineering
- Semester: III
- Subject: Circuit Analysis (CA)
- Instructor: Engr. Asif Ali
- Programming Language: Java

Project Objective

The main objective of CircuitX is to provide a simple software-based way to perform basic electrical circuit calculations. The project helps students understand circuit analysis concepts through programming.

Current Features

- Ohm's Law
- Voltage calculation
- Current calculation
- Resistance calculation

Future Features

The project can be extended in the future with:

- Kirchhoff's Current Law (KCL)
- Kirchhoff's Voltage Law (KVL)
- Voltage Divider Rule (VDR)
- Current Divider Rule (CDR)
- Circuit analysis theorems
- Graphical User Interface (GUI)
- More advanced circuit-solving features

Technologies Used

- Java
- Java Scanner
- Object-Oriented Programming concepts

How to Run

1. Install Java JDK.
2. Open the "CircuitX.java" file in a Java IDE or compiler.
3. Compile the program.
4. Run the program.
5. Select the required calculation from the menu.
6. Enter the required values.

Learning Outcomes

Through this project, I am learning how to apply circuit analysis concepts using Java programming. The project also helps improve problem-solving, programming, and software development skills.
